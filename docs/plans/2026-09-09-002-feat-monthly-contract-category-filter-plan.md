# 월별 현황 계약 구분 필터

- 현장 필터와 나란히 계약 구분 필터를 제공하며 기본값은 `전체 계약 구분`이다.
- 사용 중지된 계약 구분도 과거 조회를 위해 선택할 수 있다.
- 선택한 구분은 계약·직접·조정 매출에 동일하게 적용한다. 구분이 없는 과거 매출은 전체 조회에만 포함한다.
- 상단 합계, 현장×월 표의 숫자와 셀 상세 목록은 같은 필터 결과를 사용한다.
- Excel은 같은 기간·현장·계약 구분과 현재 선택한 매출·매입·이익 지표를 현장×월 표로 출력한다.
- 현장×월 표 구조와 현장 행은 유지하며 매출이 없는 셀은 0으로 표시한다.
- 월별 메모는 기존 현장×월 범위를 유지하고 계약 구분으로 나누지 않는다.
